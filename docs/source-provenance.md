# Source provenance

This repository is a clean-history public extraction of a maintainer-controlled
private pAI codebase. The maintainer selected the top-level MIT license for the
project source. Private history, runtime state, captured conversations, operator
configuration, credentials, deployment evidence, and private design records are
outside this repository.

The publication review found no vendored binary assets and no project source
carrying a distinct third-party copyright or license header. Generated JSON and
S-expression fixtures are synthetic project test data. The context-graph browser
assets in `scripts/context-graph-episode-lab/` are project source and have no
external JavaScript, font, image, or stylesheet dependency.

Runtime dependencies are not relicensed as pAI. Their exact resolved closure and
license classifications are recorded in [the third-party notices](../THIRD_PARTY_NOTICES.md)
and `docker/quicklisp-releases.lock`. Debian packages remain covered by their
individual Debian copyright files.

This review establishes the repository's declared provenance boundary. It is not
legal advice and does not replace a contributor's duty to identify the origin and
license of future imported code or assets.
